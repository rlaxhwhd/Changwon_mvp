대학생들의 취업역량을 위한 사이트를 기획해야해 

AI를 적극 활용해서 피드백과 로드맵을 생성하고 AI가 학생들의 길잡이 도우미 역할을 하는거야 

추가로 학생들이 이 사이트를 많이 사용하게 유도하기 위해서 재미와 경쟁유도를 위한 요소가 있어야 하는데 현재 내가 기획한 사이트맵을 알려줄게
1. AI커리어 라운지 : 진단, 역량, 학점 , 자격증, 상담내역등을 AI가 평가한 모든 항목을 종합적으로 볼 수 있는 대시보드

2. 내 성장
(1) 홈대시보드 : 퀘스트와 본인의 레벨등을 볼 수 있는 대시보드
(2) 비교과프로그램 신청
대학교에서 진행하는 비교과 프로그램들을 신청하는 곳이야볼 수 있는 곳이며 AI가 추천 적합한 비교과 프로그램을 추천
(3) 퀘스트보드 : 일일,주간,월간 퀘스트, 학과별 랭킹과 학과내의 랭킹을 볼 수 있는 곳 
(4) 성장경험일지 : 본인의 아르바이트 중 있었던 일이나 팀프로젝트에서 있었던 다양하고 소소한 일들을 적는 곳이야 이를 나중에 자소서 작성에 써먹을 수 있게 기록하는 곳이지
(5) 스킬트리 : 수강 과목을 기반으로 직무 방향의 적합도를 보여주는 스킬트리야  
3. 진단센터
(1) 취업지원검사
진로취업인식등의 성향검사를 하는 곳이야 이 검사 결과지를 토대로 AI가 분석도 해주고 로드맵 생성에 필요한 데이터야
(2) 성격유형검사

4. 상담센터 
(1) 진로취업상담 : 학교내의 상담사들에게 신청 할 수 있는 페이지
(2) 심리상담 : 학교내의 심리상담사들에게 신청할수있는 페이지
(3) 교수상담 : 본인 학과 내의 교수들에게만 신청할 수 있는 페이지

5. 경력개발로드맵

(1)AI진로로드맵 : 진단결과와 학생정보(학과, 학점, 자격증, 어학점수), 목표기업에 맞춰서 목표기업에 맞는 로드맵을 AI가 수립해주고 이에대해 앞으로 해야 할 일, 우선순위로 할 일, 보강이 필요한 역량등을 보여주는 사이트야
(2) 취업예측분석 : 목표기업과 그와 비슷한 기업들에 대해 합격 예측률을 보여주는거야 
(3) AI맞춤채용 : 학생의 현재 스펙에 맞게 적절한 기업을 추천해주는 사이트야
(4) AI자소서/면접 : AI를 통해 자소서를 쓰고 첨삭을 도와주는 사이트야 

6. 취업지원 : 채용공고들을 볼 수 있는 사이트야 잡코리아 api를 통해 가져오고 관리자가 직접 등록해서 올리는 곳이야

7. 마이페이지
(1) 포트폴리오를 제작하는 페이지야
보유 스킬, 자격증,어학, 자소서, 이력서, 본인 프로젝트 파일과 링크들을 모아놓고 수정하는 페이지
(2) 비교과프로그램 현황
신청한 비교과프로그램의 기록들 보는 곳
(3) 상담현황
교수,취업/진로,심리 상담들의 기록과 코멘트를 볼 수 있는 곳
(4) 일일미션(토익10단어)의 오답과 정답등의 기록을 날짜별로 볼 수 있는 곳

**상단 네비게이션 바 순서**
AI커리어 라운지 - 진단센터 - 상담센터 - 경력개발 로드맵 - 내 성장 - 취업지원 - 마이페이지

# 드림캐치 진로취업 진단·로드맵 프로세스 (확정안)

> 국립창원대학교 핵심 프로세스(CARE+7 / SMART)를 **보존**하면서, AI·학생데이터·게임화 요소를 **확장**한 드림캐치 MVP의 최종 진단 흐름.
> 근거 파일: `setup.xlsx`, `2. 모듈별 진단도구 모듈.xlsx`

---

## 1. 핵심 원리

거의 모든 분류는 **① 검사가 1차 자동 산출 → ② 상담사/AI가 확정·보정**하는 하이브리드다.
"검사가 정하냐 상담사가 정하냐"의 답은 → **둘 다, 역할이 다름.**

- 검사 = 데이터 기반 1차 분류·추천
- 상담사 + AI = 확정·구체화·맥락 보정

검사는 **단계별로 분할 실시**한다(한 번에 700+문항 금지). 유일한 재검사 지점은 **6단계 사후관리(미취업자 재진단)**.

---

## 2. 검사–단계 최종 배치 ⭐ (핵심)

| 단계 | 단계명 | 사용 검사 (실시 시점) | 산출물 | 결정 주체 |
|---|---|---|---|---|
| **1** | 유형진단 | **유형분류 검사**(진로명확도·역량준비도·취업준비도·진로동기, 39문항) + *(선택)* **자기이해 검사**(흥미·강점) | **학생 6유형** | 검사(자동) |
| **2** | 상담 / IAP 설정 | *검사 없음* — 1·2차 상담 + **AI 분석**(상담기록지·보고서) | **IAP 유형 R1~R6** | 상담사 + AI |
| **3** | 경력개발 로드맵 | **CARES 진로인식검사** + 학생데이터(학년·학점·자격증·수강과목) | 단(1학기)·중(1년)·장기(졸업전) 로드맵, 비교과/직무교육/현장연계 **자동 추천**, **지속 업데이트** | 검사 + AI + 데이터 |
| **4** | 역량강화 | **KVCT 직무역량검사 + E-DISC + SPRINT Ⅰ**(역량수준) | 직무군 매칭, 역량강화 비교과·외부활동·인턴 **AI 추천** | 검사 + AI |
| **5-1** | 기업연계 | *검사 없음* — M4 결과 재활용 | 기업연계 실전경험, 인턴, 일경험 | AI 매칭 |
| **5-2** | 취업지원 | **SPRINT Ⅱ**(취업준비) | **AI 자소서·AI 면접·포트폴리오·매칭 프로토콜** | 검사 + AI |
| **6** | 사후관리 | **NEO 성격검사 / 재진단** | 미취업자 재진단·재배치, 집중관리 강도 산정 | 검사 + 상담사 |

> **자기이해 검사**를 1단계에 넣으면, source에서 도구 미정으로 비어 있던 **M2 진로이해(흥미·가치·강점·성향)** 빈칸이 동시에 메워진다.
> **SPRINT Ⅰ은 역량강화(4단계), SPRINT Ⅱ는 취업지원(5-2)** 으로 분리한다(source 의도와 정합).

## 3. 전체 흐름도

```
[1단계] 유형진단
  유형분류 검사(39문항) + 자기이해 검사

        │
        ├──[분기]── 취약관리형 ─→ 집중관리 트랙(집중상담·소그룹) ─→ 회복 후 본류 합류
        │
        ├──[분기]── 우수인재형(주로 3·4학년) ─→ 가속 트랙(기업연계·멘토 조기 진입)
        │
        └──[표준]── 나머지 4유형
        │
[2단계] 상담 / IAP 설정   ← 검사 없음
  1·2차 상담 + AI 분석(상담기록지·보고서)
  → IAP 유형(R1~R6) 확정
        │
[3단계] 경력개발 로드맵
  CARES 진로인식검사 + 학생데이터(학년·학점·자격증·수강과목)
  → 단·중·장기 로드맵 + 비교과/직무교육/현장연계 자동 추천
  ↑ (이수·성과·데이터 변경 → 로드맵 자동 재계산: 양방향 피드백)

        ↑__________ 재진단 루프 ___________
```

## 4. 학생 6유형 → IAP 유형 매핑

| 학생 6유형 (1단계) | IAP 유형 (2단계) | 주 학년대 | 분기 |
|---|---|---|---|
| 진로미탐색형 | R1 탐색형 | 1·2학년 | 표준 |
| 진로설정형 | R2 설계형 | 2·3학년 | 표준 |
| 역량성장형 | R3 성장형 | 3학년 | 표준 |
| 취업준비형 | R4 취업실전형 | 4학년 | 표준 |
| 취약관리형 | R5 회복형 | 전학년 | **집중관리 트랙** |
| 우수인재형 | R6 취업완성형 | **3·4학년(고학년)** | **가속 트랙** |

> **학년**은 분기의 핵심 변수다. 우수인재형은 대부분 고학년(3·4학년)이므로 4단계 역량강화에서 곧바로 기업연계·멘토 트랙으로 가속하고, 취약관리형은 학년 무관하게 집중관리로 우선 분기한다.
