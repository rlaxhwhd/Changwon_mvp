# 퀘스트 대시보드 구현 범위

대상: `/v2/growth/quest`

## 현재 구현

- 기본 화면은 운영 준비 상태이며 실제 실적, 순위, XP를 표시하지 않는다.
- 일일 / 월간 / 학기 탭, 전체 / 진행 전 / 완료 필터, 완료 현황을 제공한다.
- 화면 체험을 켠 경우에만 예시 퀘스트를 표시한다. 예시는 운영 퀘스트 정의가 아니다.
- 체험 완료 체크와 오늘 출석체크는 React 메모리에만 존재한다. 페이지 이동, 새로고침, 체험 종료 시 초기화된다. 브라우저 저장소나 서버에 저장하지 않는다.
- 출석 달력은 월 이동과 이번 달 복귀를 지원한다. 오늘의 날짜는 한국 시간을 사용하며 포커스 복귀 및 30초 간격으로 갱신한다. 과거 출석을 추가하지 않는다.
- 출석 퀘스트와 달력 버튼은 같은 체험 상태를 사용하며 중복 체크를 방지한다.
- 활동 링크는 기존 성장 기록 / 성장일지 / 프로그램 / 채용 화면으로 이동한다. 링크 방문으로 완료 판정을 내리지 않는다.
- 가이드는 모달로 제공하며 키보드 포커스 이동과 Escape 닫기를 지원한다.
- 보상 미리보기는 구현하지 않았다. 임의의 레벨, XP, 학과 순위와 기존 고정 실적은 제거했다.

## 운영 기준 확정 후 진행할 작업

사용자 요청에 따라 이번 변경에서는 DB, API, 마이그레이션을 추가하거나 수정하지 않았다.

추후 확정할 항목:

- 운영 퀘스트 종류, 대상, 기간과 학기 시작·종료일
- 활동별 완료 증빙 및 자동 판정 기준, 취소·수정 시 처리
- 출석 인정 방식, 초기화 시각 및 중복 요청 처리
- 레벨별 필요 경험치, 경험치 지급·회수 기준
- 보상 종류와 지급 조건

기준이 확정되면 서버를 정본으로 하는 퀘스트 정의·학생 진행·출석·경험치 이력과 API를 설계한다. 현재 화면 체험 값을 학생 실적으로 이관하지 않는다.
