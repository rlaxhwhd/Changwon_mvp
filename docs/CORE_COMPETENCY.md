# 5대 핵심역량 표시 기준

2026-09-17 사용자 확정 사항.

- 핵심역량은 비교과 프로그램과 수강 강의활동을 통해 얻으며, 점수는 향후 학사 DB에서 가져온다. 외부 심리검사 결과와 구분한다.
- 강의를 이수하고 점수가 제공되는 학생은 메인과 Lounge 모두 점수를 표시한다.
- 학년·학기만으로 데이터 유무를 추정하지 않는다. 1학년 1학기에도 입학 후 바로 휴학하여 강의를 듣지 않았을 수 있다.
- 실제 점수가 없는 경우 공용 LockedContent를 통해 오각형 격자에 블러와 자물쇠를 표시한다. 임의 점수를 채우지 않는다.
- 0점은 유효한 값이며 누락과 구분한다. 현재 getCompetencyScores는 5개 축의 유한한 숫자가 모두 제공되면 표시한다.
- 학사 DB 연계 계약, 누계 환산 및 부분 누락 처리 정책은 추후 확인한다. 이번 변경에서는 학사 조회·산식을 구현하지 않는다.

## 화면 검증

- Chrome MCP로 로컬 미리보기 5178의 `/v2/main`, `/v2/lounge`를 확인했다. 개발 테스트 학생의 실제 API 점수가 두 화면에 표시된다.
- 빈 점수는 브라우저에서 프로필 응답만 null로 대체하여 검증했다. DB는 변경하지 않았다. 두 화면 모두 오각형·블러·잠금 안내가 표시되며 빈 범례는 숨긴다.
- 데스크톱과 모바일에서 가로 넘침이 없고, 재검증 콘솔 오류가 없다. 검증 도중 종료된 Vite를 재시작한 후 요청 정상화를 확인했다.
- 메인 재검증 API 29건 모두 HTTP 200, 동일 API 중복 호출 없음, 약 12~233ms. 기존 초기 로딩 프로그램 약 693KB, 채용 약 733KB 응답은 남아 있다. 신규 API 호출은 없다. 서버·DB 성능 개선 작업은 수행하지 않았다.
- 원래 Docker 웹 서버에 배포하지 않았으며, 소스와 로컬 미리보기에 반영했다.
