# 성장 포트폴리오 입력 사전

`/v2/growth`에서 본인의 프로젝트, 스킬, 자격·어학, 활동 기록을 입력한다.
추천 항목 선택은 입력란만 채운다. 저장 버튼을 눌러야 본인 자기신고 기록이 생성된다.

## 운영 관리

최고관리자 코드관리에서 아래 그룹의 명칭·정렬·사용 여부와 분류를 편집한다.
후보 추가와 비활성화는 감사 이력을 남기며 `/api/v1/metadata`로 화면에 전달된다.
학생 화면은 포커스 복귀 또는 30초 주기로 메타데이터를 갱신한다.

| 그룹 | 초기 항목 수 | 추가 정보 |
|---|---:|---|
| GROWTH_SKILL_CATEGORY | 17 | 스킬 분류 |
| GROWTH_SKILL_OPTION | 330 | categoryCode: 사용 중인 스킬 분류 코드 |
| GROWTH_CERT_OPTION | 135 | category: 자격 분야 |
| GROWTH_LANGUAGE_OPTION | 30 | language: 시험 언어 |
| GROWTH_PROJECT_EXAMPLE | 20 | 프로젝트 제목 예시 |
| GROWTH_ACTIVITY_EXAMPLE | 30 | categoryCode: 성장 기록 분류 코드 |

초기 목록은 `075_growth_input_catalog.sql`로 추가한다. 이후 변경은 코드관리에서 수행한다.
학교 자격 원천 사전이나 취득 사실을 추가하는 마이그레이션이 아니다.
자격 후보는 입력 편의를 위한 것으로, 발급기관·점수·등급·날짜는 증명서를 보고 본인이 입력한다.
시험별 점수 범위나 유효기간은 임의로 강제하지 않는다.

## 저장 계약

- 스킬 분류는 한글 표시명이 아닌 `GROWTH_SKILL_CATEGORY`의 코드로 저장한다.
- 자격증은 `CERTIFICATE`, 어학시험은 `LANGUAGE`로 저장하며 기존 성장 API 계약을 사용한다.
- 어학은 언어·시험명·점수/등급, 자격증은 기관·자격번호·점수/등급을 기록한다.
- 목록에 없는 항목은 직접 입력할 수 있다. 후보를 비활성화해도 기존 학생 기록은 삭제되지 않는다.
- 기존 기록 종류는 변경할 수 없다. 저장 실패 시 모달과 입력값을 유지한다.

입력 항목 구성은 [사람인 이력서 등록 가이드](https://www.saramin.co.kr/zf_user/help/help-word/view?idx=616&keyword=%EC%9D%B4%EB%A0%A5%EC%84%9C&list_idx=0&page=1)의 자격/어학·경험 입력 방식을 참고했다.
후보는 이 프로젝트에서 구성했으며 특정 채용사이트의 전체 사전을 복제한 자료가 아니다.
