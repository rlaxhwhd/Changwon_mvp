# 비교과 맞춤 추천

2026-09-14 사용자 확정: `/v2/growth/program`의 **AI 맞춤 추천**은 이름만 AI이며, 모델 호출 없이 DB 필터로 제공한다.

- 버튼을 누르면 `GET /programs?recommended=true`를 호출한다. 서버가 인증된 학생의 최신 `dc.student_type_event.student_type`을 조회하여 `dc.program.care_types`에 포함된 프로그램만 반환한다. 클라이언트가 다른 학생의 유형을 지정하지 않는다.
- 모집 중(`RECRUITING`)이고 마감일이 지나지 않은 프로그램을 신청 마감일 오름차순으로 정렬한다. 마감일 미정은 마지막, 같은 날짜는 프로그램 ID순이다. 상단 고정 여부는 추천 순서에 영향을 주지 않는다.
- 유형이 없거나 해당 유형의 프로그램이 없으면 다른 프로그램으로 대체하지 않는다. **현재 추천 가능한 프로그램이 없습니다**를 표시한다.
- 실제 API 요청 동안 로딩을 표시한다. 실패는 빈 결과와 구분해 오류와 재시도 동선을 제공한다. 임의 지연과 AI 분석 안내는 제거했다.
- 기존 프로필의 `recommendations.programs`는 이 화면의 추천 데이터로 사용하지 않는다. 기본 프로그램 목록과 추천 목록은 독립적이다. 기존 DB 구조를 사용하므로 마이그레이션은 필요 없다.

검증: 유형 매칭·유형 없음·빈 결과·마감일 정렬·오늘 마감 포함·종료/마감 프로그램 제외·페이지 분할·교직원 접근 제한 테스트 3개. TypeScript 빌드 통과. 변경 파일 ESLint 오류 0개(기존 wishRevision 경고 1개).

브라우저 검증: 격리 테스트 DB의 학생 로그인 세션으로 추천 0건/2건 표시 및 빈 결과 안내를 확인했다. 콘솔 오류 0개. 실제 DB에는 테스트 프로그램을 추가하지 않았다.
