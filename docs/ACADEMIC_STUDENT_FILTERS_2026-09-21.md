# 학사 전체 학생 필터·엑셀·공용 상세

## 사용자 확정

- 전체 학생 화면에 졸업년월 범위, 성별, 조회인원 100/200/300 필터와 엑셀 다운로드를 제공한다.
- 학생 행은 공용 학생정보 모달로 연다. CARE 7+ 참여 여부가 기본정보와 활동 표시 조건이 아니다.
- `V_USR_INF.GRADE`는 원천 평점으로 그대로 표시한다(0도 유효). `SEX`는 0001 남자, 0002 여자이다. `OUT_DT`는 졸업일이다.
- 외부 상담·비교과 이력은 현재 로컬에 복제되어 있지 않다. 연결된 현재 기록을 표시하고 없는 항목은 ‘없음’으로 표시한다. 외부 이력이 없었다고 단정하지 않는다.

## 구현

- 097 마이그레이션은 성별·원천 평점·졸업일만 노출하는 `dc.academic_student_details` 읽기 뷰를 추가한다. 원천 수정이나 academic 스키마의 앱 계정 직접 접근을 허용하지 않는다.
- 졸업 상태(0005)의 형식이 유효한 OUT_DT에서 YYYY-MM을 읽는다. 시작·종료월을 포함한다. 역전 범위/잘못된 월은 422로 거부한다.
- 필터는 서버 목록과 엑셀에서 같은 함수로 해석한다. 대학·학과·학년·학적·학부/대학원·성별·졸업년월·검색을 함께 적용할 수 있다.
- Excel은 페이지 제한 없이 필터 결과 전체를 XLSX로 생성한다. 서버 커서와 임시파일로 대량 결과의 메모리 사용을 제한한다. 셀을 inlineStr로 작성하여 학번 앞자리 0과 수식처럼 보이는 문자열을 보존하고 수식으로 실행하지 않는다. 추가 패키지는 없다.
- `StudentDetailModal` → `StudentDetailView` 공용 경로에 academic 읽기를 연결했다. 기존 접근 가능한 학생은 기존 상세 탭을 유지하며, 미가입 학생도 공용 기본정보·요약 카드와 상담/비교과 이력을 표시한다. 원천 평점은 CARE 진단과 별개이다.
- 일반상담을 포함한 취소되지 않은 신청·확정·완료 기록을 상세 요약에 표시한다. 비공개 상담 주제·일지·접수 내용·심리검사 결과는 이 학사 API로 노출하지 않는다.
- 비교과는 program_apply와 student_program_history를 읽고 동일 학생·프로그램은 현행 신청을 우선하여 중복 제거한다. 비교과 이수 집계와 상세 목록에 같은 기존 이력을 반영한다.
- 학사 목록·엑셀·상세는 모두 students.1 메뉴 권한을 검사한다. 상세 집계 조회는 편집·상담일지·로드맵 권한을 부여하지 않는다.

## 검증

- 새 테스트 DB `dc_regression_20260921070636_5993b0_test`에서 마이그레이션 및 API 테스트. 최종 `test_academic_students.py` 6건 통과.
- 미가입 상세, 성별·졸업월 복합 필터, 100/200/300 크기 및 상한, 역전 범위, 엑셀 필터 일치/선행 0/수식 안전성, CARE 미참여 일반상담·비교과 이력, 비공개 필드 제외 검증.
- TypeScript 검사와 Docker 빌드 통과.
- Chrome 실제 화면: 각 조회인원에 맞는 행 수, 2020-02 졸업·여자 834명(DB와 일치), 엑셀 버튼 21,743바이트 XLSX, 미가입 학생 공용 모달/평점/없음 표시, 가로 넘침·콘솔 오류 없음 확인.
- 해당 복합 필터 조회 459ms, 엑셀 응답 316ms, 미가입 상세 361ms(이 PC에서 측정, 보장값 아님).
- 전체 엑셀 92,514행(헤더 제외), 2,535,679바이트. 다운로드와 ZIP/XML 행 수 검증 합계 17.93초. 파일 내용이나 학생 원본은 문서에 보관하지 않았다.

## 복구

앱 코드를 이전 버전으로 배포한 뒤 새 forward 마이그레이션에서 `DROP VIEW dc.academic_student_details`로 되돌릴 수 있다. 적용된 097은 수정하지 않는다. 기존 학사/서비스 행은 변경하지 않았다.
