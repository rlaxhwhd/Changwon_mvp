# 비교과 설문 버전 선택·미리보기

## 확정 기준

- 등록 및 관리의 수정 화면에서 게시된 역량·만족도 설문 버전을 각각 선택한다. 설문없음은 해당 조사를 미실시한다.
- 사용자가 확정한 기준: 해당 종류의 응답 전까지 버전을 변경할 수 있고, 응답 후에는 고정한다. 역량은 PRE/POST 중 하나라도 있으면 고정하며 만족도는 독립적으로 판정한다.
- PRE와 POST는 동일한 competency_form_id 및 선택 영역을 사용한다. 새 게시본이 나와도 기존 프로그램의 선택본이 자동 변경되지 않는다.
- 첨부 이미지의 설문 이름·문항 데이터는 추가하지 않았다. 현재 개발 DB의 게시본은 종류별 v1이다.

## 구현

- 기존 program의 FK 컬럼과 publishedSurveyForms 메타데이터 재사용. 스키마 마이그레이션 없음.
- 프로그램 생성·수정 API가 competencyFormId/satisfactionFormId를 검증·저장한다. 존재하지 않는 ID, 다른 종류, 초안은 422. 생략 시 신규는 최신, 수정은 기존 선택본을 유지한다.
- 선택 버전이 바뀌면 역량 영역을 해당 버전으로 재검증한다. 이미 응답한 프로그램은 버전과 역량 영역 변경을 차단한다.
- `GET /programs/{id}/survey-locks`: 교직원 전용. 조회 범위에 포함된 신청자만으로 판단하지 않고 프로그램 전체의 응답 존재 여부를 확인한다.
- 버전 변경과 학생 제출은 같은 program 행의 FOR UPDATE를 사용한다. 변경 요청은 잠금 획득 뒤 응답 여부를 확인하며 기존 expectedVersion 충돌 처리도 유지한다.
- 공통 SurveyQuestions로 미리보기·학생 문항 렌더링 공유. 파란 제목줄/Q 표시, 테두리 제목, 세로 선택지, 점선 구분. 5점 척도의 단일 선택 및 선택 서술형 계약 유지.
- native dialog로 미리보기 팝업, 확대/복원·닫기·인쇄 버튼. 미리보기 입력은 컴포넌트 상태에만 보관하고 제출 요청을 하지 않는다. 닫으면 호출 버튼으로 초점을 복원한다.
- 역량 미리보기는 현재 체크한 영역만 표시한다. 미리보기 코드는 클릭 시 지연 적재한다.

## 검증

- 격리 DB `dc_regression_20260928085933_e4ffed_test`의 관련 테스트 **44 passed, 317 deselected**. 기존 Starlette deprecation 경고 2건.
- 신규/구버전 선택, 초안·종류 불일치·없는 ID 거절, 응답 전 변경, PRE/POST 및 만족도 독립 잠금, 영역 재검증, 학생 권한 차단, 낙관적 버전 충돌 검증.
- 변경 TS/TSX ESLint 및 전체 build 통과. admin 번들 약 501.81kB의 Vite 청크 크기 경고는 남아 있다.
- Chrome MCP 실제 `localhost:5173`: 등록 선택지·미리보기 18문항, 기존 프로그램의 선택 영역 미리보기 25문항, 역량 버전 잠금/만족도 선택 가능, 확대·닫기·포커스 복원, 학생의 기존 25개 답변 표시 확인.
- 별도 API 18103/Vite 5174로 위 격리 DB에 연결하여 실제 UI 등록(v1) → 응답 전 수정(다른 게시본) → 학생 4문항 응답·제출(201) → 현황 이동 → 재진입 시 읽기 전용 확인. 테스트 DB에만 로그인 fixture·시험 프로그램·응답을 추가했다.
- 학생 화면 실측 500px에서 가로 넘침 없음. 실제 프린터 출력은 수행하지 않았다.
- 마지막 확인한 실제 화면 콘솔 오류/경고 없음. 성공 경로의 API HTTP 오류 없음. 초기 격리 DB 로그인 fixture 누락으로 401이 발생했으나 테스트 DB에 fixture를 준비한 뒤 로그인·신청·선발·제출 모두 정상 확인했다.
- 관측: 실제 잠금 API 200/174ms/40B, 격리 DB 설문 GET 200/97ms/950B, POST 201/59ms/96B. 개발 StrictMode 초기 조회는 취소된다. 숫자는 브라우저 시간이며 서버·DB 시간과 구분한다.
- 잠금 조회 EXPLAIN ANALYZE: 기존 `survey_response_program_id_student_uid_phase_key` Index Only Scan 2개, 실행 0.335ms(격리 소규모 DB). 추가 인덱스 없음. 별도의 동시 부하 시험은 수행하지 않았다.
- 로컬 Docker API 재빌드 및 healthy 확인. 5173에서 변경 코드 검증. 운영/공유 배포·Git push 없음.

## 복구

코드 되돌림으로 화면/API를 이전 동작으로 복구할 수 있다. 선택한 FK는 기존 스키마와 호환되므로 DB 구조 복구가 필요하지 않다. 저장된 프로그램의 설문 버전이나 응답을 일괄 변경하는 작업은 하지 않았다.
