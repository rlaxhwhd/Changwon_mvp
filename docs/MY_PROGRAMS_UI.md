# 학생 비교과 현황

대상: `/v2/mypage/programs`. 2026-09-21 실제 데이터 연결.

- 예시 8개 삭제. `GET /api/v1/programs/mine?page=1&pageSize=100`을 사용한다. 서버 인증 학생의 `program_apply.student_uid`로 범위를 제한한다. 다른 학생 ID를 입력하는 계약은 없다. 교직원 요청은 403.
- 기존 정규화된 `dc.program`과 `dc.program_apply`, 학생별 `program_apply_student` 인덱스를 재사용한다. 신규 테이블/마이그레이션은 필요 없다. 관리자의 선발·이수 기록과 학생의 신청·취소가 기존 저장 API를 통해 같은 테이블에 반영된다.
- 목록은 100건씩 조회하며 학생 자신의 전체 내역에 필터/요약/캘린더를 적용한다. 큰 HTML, 이미지, 타인의 신청 정보, 개인정보는 응답에 포함하지 않는다. 전역 bootstrap의 기존 프로그램 카탈로그 조회는 별도로 존재하며 이번 작업에서 제거하지 않았다.
- 재진입 및 PROGRAM_EVENT 발생 시 갱신. 이전 요청은 언마운트 시 중단한다. 로딩·오류·재시도·빈 내역을 표시한다.
- 분류/선발/이수/출석 명칭은 기존 코드관리 label 함수를 import한다. 운영 종료일만으로 수료를 추정하지 않는다. 이수 결과 COMPLETED가 수료 기준이며 취소 신청은 제외한다.
- 달력은 운영 기간(run_start/run_end) 중 선발·수료 내역을 표시한다. 취소·탈락 제외, 일정 미정은 날짜 필터/달력에서 제외한다. 일별 배열을 무한 확장하지 않고 화면에 보이는 날짜별로 계산한다. 신청일은 한국 시간 기준.
- 실제 저장 필드인 담당자·운영 회차·장소·출석을 상세에 표시한다. 존재하지 않는 인정시간·XP·회고 예시를 제거한다. 학생 화면에 CSV는 제공하지 않는다.
- 상담 현황과 HistoryCalendar 및 공통 스타일을 재사용한다. 블루 기본 조작, 초록 수료/보조 요약/안내 카드, 보라 일정 요약/캘린더를 적용한다. 기존 셸 여백과 폰트 유지.

검증:
- PostgreSQL 통합 테스트: 본인 범위, 다른 학생 제외, 교직원 차단, 페이지 크기 제한, 취소 유지, 일정 미정, 큰 본문 제외 통과.
- 프로덕션 빌드 및 대상 ESLint 통과.
- Chrome MCP: 테스트 DB의 본인 2건과 화면 2건 일치, 취소 필터 1건, 상세 일정 미정, CSV 미노출, 콘솔 오류/경고 없음. 500px 가로 넘침 없음 및 1440px 화면 확인. 관리자 상담기록에도 공용 색상 반영 확인.
- 동일 테스트 환경에서 mine 요청 HTTP 200, 약 18ms/814바이트. EXPLAIN ANALYZE 2행 실행 약 0.105ms, 계획 약 0.392ms. 소규모 테스트 측정이며 운영 규모 성능을 보장하지 않는다.
- API 코드 변경이므로 실행 중인 사용자 API 프로세스는 reload 또는 재시작이 필요하다. 검증용 API(18123)는 재시작했다.
