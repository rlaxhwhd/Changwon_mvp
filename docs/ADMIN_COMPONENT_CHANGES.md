# 관리자 컴포넌트 불일치 수정 결과

작업일: 2026-09-15

## 적용 범위

관리자 화면의 버튼, 입력 컨트롤, 탭, 표 머리글, 페이지 이동, 상태 배지, 요약 카드, 폼 하단, 빈 상태, 아바타, 편집기 외형을 정리했다. 기존 데이터·검색 조건·저장 처리·권한 정책은 유지했다.

이 문서는 앞서 작성한 디자인 점검 목록의 **컴포넌트 표현과 재사용에 대한 수정 결과**다. 35개 점검 항목 전체를 해결했다는 의미는 아니다.

## 공통 규격과 재사용

| 요소 | 적용 내용 |
|---|---|
| 기본 버튼 | 높이 44px, 글자 14px/700, 모서리 12px. 채움/테두리 버튼에 같은 크기 적용 |
| 소형 버튼 | 높이 36px, 글자 13px. 표 안의 동작 버튼과 홈의 소형 버튼에 적용 |
| 검색·선택 | 관리자 공통 검색창과 선택창 높이 44px, 모서리 12px. 블랙리스트 검색창도 공통 스타일 사용 |
| 다운로드 | 상담일지·비교과·지원자·블랙리스트·교수 배정의 다운로드를 공통 테두리 버튼으로 통일 |
| 탭 | 상담 접수 상태 탭과 로드맵 조회 범위 탭에 기존 `admin-tabs` 스타일 적용 |
| 표 | 공통 로스터 머리글을 옅은 회색 배경, 최소 높이 48px, 글자 13px로 정리. 열 구성은 업무별 유지 |
| 페이지 이동 | `AdminPagination`으로 학생·진단·교수·조교 목록 및 학생 선택 모달 통합. 블랙리스트의 숫자형 이동도 같은 컴포넌트의 변형 사용 |

| 폼 하단 | `AdminFormActions`로 저장·닫기·취소 영역 재사용. 2열 폼에서도 전체 열을 차지하고 우측 정렬 |
| 빈 상태 | 기존 `EmptyState`에 소형 변형 추가. 학생 상세에서 재사용하고 관리자 채용 목록에도 주입 |
| 프로필 | `AdminAvatar`로 사람 아이콘 대체 표시 공통화 |
| 편집기 | RichEditor 테두리·모서리·도구막대·36px 도구 버튼 정리. 등록 폼의 파란 강조색 유지 |

## URL별 수정 내용

`:studentId`, `:programId`, `:jobId`는 실제 데이터 ID가 들어가는 자리다. 예: `/admin/students/chaewon`, `/admin/programs/prog_001/applicants`.

## 검증 결과

- 최종 `npm run build` 통과: `tsc -b` 타입 검사 및 Vite 프로덕션 빌드.
- `git diff --check` 통과.
- 브라우저에서 진로취업상담사·심리상담사·교수·조교 화면 확인.
- 학생 목록: 검색창·선택창·검색 버튼 모두 44px, 페이지 이동 버튼 36px 확인. 다음 페이지 이동 시 `2 / 6 페이지` 확인.
- 블랙리스트: 숫자형 2페이지 이동 및 현재 페이지 표시 확인, 벌점 모달 하단 우측 정렬 확인.
- 교수 접수: 최초 로딩 표시, 긴 주제 줄바꿈, 내용 폭 버튼·배지, 일정 확정 모달의 전체 열 우측 정렬 확인.
- 집단상담 개설 모달: 입력창·일시 필드·닫기/개설 버튼 시각 확인.
- 학생 상세: 8개 탭을 모두 전환해 각 본문 시작 간격 16px 확인.
- 심리검사: 4개 카드 너비가 동일하고 라벨 시작 높이가 동일함을 확인.
- 상담사·교수 프로필: 아바타 내부 사람 SVG 표시 확인.
- 홈: 학생정보/브리핑/AI 추천 질문 36px·13px, 문진표/상담 진행 44px·14px 확인.
- 프로그램 등록: 편집기 렌더링, 도구 버튼 36px, 하단 우측 정렬, 파란 버튼 `rgb(37, 99, 235)` 유지 확인.
- 채용 목록·관리: 공통 빈 상태 표시 확인. 학생 `/v2/jobs`에서는 기존 빈 상태가 유지됨을 확인.
- 상담 통계·로드맵 통계·프로그램 목록·채용 등록·상담 진행의 렌더링 확인. 상담 진행의 h1은 화면 제목 하나임을 확인.
- 프로그램 신청자 화면은 1280×900에서 표와 가로 스크롤 확인. 주요 시각 비교는 1440×1000 사용.
- 확인한 브라우저 콘솔에 오류 없음. 데모 역할을 김진로로 복원하고 임시 화면 크기 설정 해제.

저장·삭제·배정·선발 등 데이터 변경 동작은 실행하지 않았다. 교내 채용공고가 없어 개별 공고 수정·지원자 상세의 실제 데이터 상태는 공통 소스와 빌드로 확인했다.

## 유지한 범위와 후속 항목

- 검색의 즉시 반영/버튼 실행 방식, 행 클릭/상세 버튼 진입 방식, 상담 처리 모달의 정보 순서, 저장·확인 대화상자의 동작은 유지했다.
- 학생과 공유하는 JobBoard의 카드·필터 디자인 및 StudentStatCards의 원형은 유지했다. JobBoard에는 관리자 빈 상태를 주입하는 선택 속성만 추가했다.
- 프로그램 등록의 파란 테마, 채용 등록의 좌측 라벨 폼, 인쇄 서식은 의도된 변형으로 유지했다.
- 홈의 1280px 레이아웃, 플로팅 챗봇 가림, 메뉴·경로·제목 아이콘, 데이터 상태/집계, 문구 정비는 이번 컴포넌트 수정에서 해결한 항목으로 계산하지 않는다.
- 홈은 실제 사용하는 `TestAdminHome.css`를 수정했다. 기존 점검 문서에 인용된 `Home.css`는 현재 Home.tsx가 가져오는 파일이 아니며 이번 변경 대상에서 제외했다.
- 이전 작업의 GNB 서브메뉴 통일·화살표 제거 변경은 그대로 보존했다.
