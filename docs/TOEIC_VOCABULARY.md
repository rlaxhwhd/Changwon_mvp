# TOEIC 영단어 풀

## 관리 화면

`/admin/quests/missions` → TOEIC 영단어

번호(고정 문제 ID), 영어단어와 뜻, 난이도, 출제횟수를 표시한다. 번호는 목록 행 번호가 아니므로 삭제·사용 중지 또는 다른 유형의 등록에 따라 건너뛸 수 있다.
난이도 필터, 검색, 영어단어순·출제 적은 순·최근 등록순 정렬, 현재 페이지 일괄 선택을 지원한다. 주간 최대 선택 개수는 10개 또는 20개로 설정한다. 랜덤 생성은 기존 선택을 유지하고 현재 조건의 전체 풀에서 부족한 수만 추가한다.

## 정규화 구조

- `dc.mission_question`: 공통 문제 ID, 뜻(prompt), 분류, 예문·해설 등 기존 출제 내용.
- `dc.toeic_vocabulary`: `question_id` 기본키이자 FK, `english_word`, `difficulty_code`. 기존 문제와 1:1 연결한다. 기존 문제 ID와 풀이의 참조는 유지한다.
- `dc.code_item`: `TOEIC_DIFFICULTY` 그룹의 LOW/하, MEDIUM/중, HIGH/상. 코드관리에서 표시 이름·순서·활성 여부를 관리한다. 임의 난이도 코드는 API에서 거부하고 DB FK로 참조 무결성을 보장한다.
- `dc.mission_question_publication`: `question_id`, `week_id` 복합 기본키, `first_published_at`. 단어별 출제 횟수는 이 표의 행 수를 조회해 계산하며 별도 누적 숫자를 저장하지 않는다.

같은 영어 철자라도 뜻·문항이 다른 기존 항목은 유지한다. 출제횟수는 영어 철자 문자열 전체가 아니라 고정 문제 ID 기준이다. 기본 카탈로그 추가 시에는 기존 영어 철자와 중복되는 항목을 추가하지 않는다.
난이도와 문제 ID 복합 인덱스, 영단어 소문자 인덱스, 출제 이력 양방향 참조 인덱스를 둔다. 큰 규모에서 부분 문자열 검색 부하가 확인되면 trigram 등 검색용 인덱스를 별도로 도입할 수 있다.

이전 API와의 전환 호환성을 위해 기존 `mission_question.content.word`는 당분간 함께 저장한다. 새 API는 정규화한 `toeic_vocabulary.english_word`를 정본으로 읽고 저장 시 두 곳을 한 트랜잭션에서 갱신한다. 구버전 서버를 정리한 후 이 중복 키를 제거하는 별도 전진 마이그레이션을 적용할 수 있다.
주간 게시물 및 학생 풀이의 문제 사본은 당시 문항·정답을 보존하기 위한 의도적인 비정규화다. 이력 보존을 위해 원본 단어를 수정해도 해당 사본을 갱신하지 않는다.

## 횟수 기준

- 비공개 저장: 출제횟수 증가 없음.
- 최초 주간 게시: 해당 문제에 1회.
- 같은 주에 수정·재게시·제외 후 다시 포함: 추가 증가 없음.
- 다른 주에 게시: 추가 1회. 미래 주간 예약 게시도 출제 등록으로 집계한다.
- 게시 후 비공개 또는 주간 목록에서 제외: 과거 출제 이력은 남긴다.
- 학생 풀이 횟수는 출제횟수에 포함하지 않는다.

080에서 기존 관리자 게시 감사 이력과 현재 게시 중인 목록을 바탕으로 기존 출제를 복원한다. 과거 숫자를 임의 생성하지 않는다.

## 카탈로그와 난이도

기존 기본 어휘 40개에 독립적으로 구성한 업무·생활 어휘 300개를 추가했다. 기본 340개이며 관리자 등록 단어는 별도로 유지한다. 자동 게시하지 않는다.

하: 기본 생활·업무에서 접하는 단어.
중: 일반 비즈니스 활동·문서·채용·행사 관련 어휘.
상: 추상적 개념·계약·재무·조직 관리와 관련된 어휘.

이는 운영 시작을 위한 편집상 분류이며, 공식 TOEIC 출제 빈도·점수·CEFR 등급을 뜻하지 않는다. 관리자는 난이도를 바꿀 수 있다. 기존 관리자 작성 문항에는 임시 중 분류를 사용하며 문제 본문은 덮어쓰지 않는다.

참고한 공개 자료:
- ETS TOEIC Listening and Reading: 업무 환경 영어라는 범위 참고. https://www.ets.org/toeic/about/listening-reading.html
- Cambridge B1 Preliminary vocabulary list (August 2025): 일반 학습 어휘 범위와 어휘 목록의 비완결성 참고. https://www.cambridgeenglish.org/Images/506887-b1-preliminary-vocabulary-list.pdf

공개 자료의 어휘 등급을 TOEIC 상·중·하에 기계적으로 대응시키지 않았다. 단어 목록·한국어 뜻·초기 난이도는 직접 구성했으며, 웹사이트의 예문·문제·정의 본문을 복사하지 않았다.

## 마이그레이션 및 검증

079: 신규 스키마만 추가. 080: 난이도 코드·기존 어휘·게시 이력 이관. 081: 신규 카탈로그 데이터.
기존 적용 파일 076~078은 수정하지 않는다. 테스트 DB에서 먼저 검증한 뒤 로컬에 적용한다. 테스트 DB의 기존 062 체크섬 불일치는 유지하고 079~081만 마이그레이션 잠금과 이력 기록을 포함한 트랜잭션으로 적용했다.

롤백은 새 전진 마이그레이션/호환 앱 배포로 수행하고 출제·학생 풀이 이력은 삭제하지 않는다. 구버전 앱으로 복귀하는 동안 문제 편집·게시는 중단하여 정규화 테이블과 기존 JSON이 어긋나지 않게 한다.

API 테스트는 난이도 변경·필터·코드 검증·기본 데이터, 최초 게시·같은 주 재게시·다른 주 게시·비공개 처리의 집계, 기존 미션 채점 계약을 검증한다.
