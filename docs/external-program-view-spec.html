비교과 프로그램 View 데이터 요청 항목

목적: 외부 비교과 프로그램을 학생별 IAP 로드맵 추천에 활용

기준 자료: 프로그램 개설 정보 화면 1~6. 아래 항목과 제공 범위는 업체 협의용 초안입니다.

‘연계용 추가 항목’은 사진에 직접 보이지 않지만 중복 방지·신청 연결·변경 반영을 위해 요청하는 항목입니다. 세부 주제 항목은 화면의 주제 사용 기능을 기준으로 제안하며 실제 제공 구조는 확인이 필요합니다.

2. 데이터 제공 범위 — 협의안

상위 그룹데이터 범위
프로그램 범위학교 전체 운영기관·학과의 비교과 프로그램. 대상 제한 정보도 함께 제공
모집·운영 상태모집 예정·모집 중·마감·운영 중·종료 프로그램 포함 제안. 마감·종료된 프로그램은 이력 유지용으로 받고 신규 신청 추천에서는 제외
과거 데이터 기간제공 시작 연도는 별도 협의. 특정 연도로 확정하지 않음
임시저장·비공개신규 추천 대상에서 제외. 이미 제공된 프로그램이 비공개로 바뀌면 해당 ID와 상태 변경 정보 제공
폐강·취소·삭제신규 추천 대상에서 제외. 이미 제공된 프로그램은 ID와 변경 상태를 전달하여 기존 추천에서도 해제할 수 있도록 함
반복 개설·세부 주제반복 개설은 개설 건별로 구분. 주제별로 신청을 받는 경우 주제별 ID·일정·신청정보 제공
신청 대상 값전체 허용·대상 없음·미설정 값을 구분. 학적·학년·소속·성별·교과목 등은 코드와 코드명을 함께 제공
특정 대상자 한정한정 여부만 우선 제공. 학생별 대상 확인 방식이 합의되기 전에는 자동 추천에서 제외하는 안으로 협의
이번 요청 제외신청자 개인정보·개인별 이수내역, 예산, 개설근거·증빙, 게시판 설정, 설문 문항·응답, 이수증·우수상 양식, 알림 발송 설정, 표지이미지

View는 조회 전용으로 요청합니다. 값이 없는 항목은 ‘없음’과 ‘미제공’을 구분하고, 코드값 설명·일시 기준·갱신 주기는 업체와 확인합니다. 개인별 이수 자동 반영은 별도 연계 범위입니다.
