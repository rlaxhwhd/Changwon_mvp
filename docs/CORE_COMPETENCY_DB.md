# 핵심 5대역량 DB

2026-09-14 사용자 지시: 핵심역량은 교과·비교과에 배정된 비율과 인정 실적에서 집계한다. 학사 과목 배점은 향후 학사 DB에서 가져온다. 우선 DB 구조를 구성하며 진단·로드맵·내성장 퀘스트와 연결하지 않는다.

## 구성 — 마이그레이션 065

| 객체 | 역할 |
|---|---|
| `dc.core_competency` | 기존 화면과 같은 5개 축의 코드·이름·순서 |
| `dc.core_competency_allocation` | 과목 또는 비교과별 배점 원천·개정 버전·활성 여부 |
| `dc.core_competency_allocation_axis` | 버전별 5개 축의 비율과 원천 배점 |
| `dc.core_competency_allocation_status` | 비율 구성과 배점 연계 완전성 확인 |
| `dc.student_core_competency_activity` | 실제 이수·수료 내역과 해당 배점을 연결하는 조회 뷰 |
| `dc.student_core_competency_status` | 실적 없음·배점 누락·집계 준비 여부 |
| `dc.student_core_competency_points` | 준비된 학생의 축별 원천 배점 누계. 화면용 100점 환산 점수가 아님 |

새 학생 실적 테이블은 만들지 않는다. 교과는 `dc.student_course.finish_yn='Y'`, 비교과는 `dc.program_apply.outcome_code='COMPLETED'`이며 취소되지 않은 건을 인정 근거로 사용한다. 신청·수강 중·선발·출석만으로 점수를 부여하지 않는다. 이수·수료 취소는 조회에 즉시 반영된다. 향후 학교가 수료 외 인정 조건을 제공하면 별도 마이그레이션으로 반영한다.

## 학사 배점 연계 계약

- 과목은 기존 `dc.subject.curi_num`에 연결하고 적용 연도·학기를 정확히 일치시킨다. 다른 학기나 최신 버전으로 대체하지 않는다. 기존 `student_course`의 학생·연도·학기·과목 키를 재사용한다. 학사 원천이 분반별 배점을 제공한다면 현재 수강 키의 확장이 먼저 필요하다.
- 비교과는 `dc.program.id`에 연결한다. 기존 `competency_areas`는 영역 선택값이므로 배점으로 해석하지 않는다.
- `source_system`, `source_key`, `source_revision`으로 원천을 추적한다. 같은 원천·키·버전의 중복 반입을 거부한다. 최신 학사 정보를 주기적으로 가져오는 수집기는 이번 범위가 아니다.
- 비율은 0~1의 정확한 `numeric` 값으로 저장한다(20% → 0.2). 5개 축을 모두 명시하고 합계가 1이어야 집계 준비로 판정한다. 해당 없는 축도 원천 확인 후 0을 명시하며 누락된 축을 임의로 채우지 않는다.
- `allocated_points`는 인정 실적 1건의 **공식 축별 배점**이며 모르면 NULL이다. 비율만 수신한 경우 배점 총량·환산 기준을 확인한 뒤 채운다. 학점이나 100점을 임의의 총량으로 사용하지 않는다.
- 개정은 새 배점 버전을 만들고, 한 트랜잭션에서 기존 버전을 비활성화한 뒤 새 버전을 활성화한다. 같은 과목·학기 또는 같은 프로그램의 활성 버전은 하나뿐이다. 실적이 사용하는 배점도 활성 버전에 따라 바뀐다. 원천 개정 기록은 이전 행으로 보존한다.
- 런타임 `dc_app`에는 SELECT만 부여했다. 반입은 DB 소유자 권한으로 수행하며 공개 작성 API는 없다. 원본 Oracle에는 작업하지 않는다.
- 066은 신규 테이블의 조회 계획 통계를 초기화한다. 배점 대량 반입 후에도 세 테이블에 `ANALYZE`를 실행한다.

## 빈 값과 집계 범위

| 상태 | 의미 | 점수 뷰 |
|---|---|---|
| `NO_ACTIVITY` | 현재 서비스 DB에 인정 실적이 없음 | 행 없음 |
| `ALLOCATION_MISSING` | 실적에 연결할 활성 배점이 없음 | 행 없음 |
| `ALLOCATION_INCOMPLETE` | 축 누락 또는 비율 합계 불완전 | 행 없음 |
| `POINTS_MISSING` | 비율은 있으나 공식 배점이 없음 | 행 없음 |
| `READY` | 모든 실적의 5개 축 배점이 연결됨 | 축별 원천 배점 누계 5행 |

학년이나 편입 여부로 점수를 만들지 않는다. 실적 없는 1학년·3학년 모두 점수 행이 없다. 반면 실제 배점이 0인 실적은 0점 행으로 구분한다. 일부 실적만 연결된 학생에게 부분 합계를 전체 점수로 제공하지 않는다.

`NO_ACTIVITY`는 현재 DB에 근거가 없다는 뜻이며, 원천 동기화가 완료됐다는 보장은 아니다. 화면 연결 시 학사 연계 상태도 별도로 확인해야 한다.

누계는 이수 건별 원천 배점을 단순 합산한 기술적 조회다. 재수강 중복 인정, 편입 인정학점, 기간 제한, 교과·비교과 간 환산, 100점 정규화, 목표선·등급·순위 정책은 구현하지 않았다. 이런 규칙이 확정되기 전 누계를 최종 역량 점수나 학생 판정에 사용하지 않는다.
