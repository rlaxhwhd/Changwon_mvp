# 학생 상담 현황 화면 개편 (2026-09-21)

대상: `/v2/counsel/record`, `src_v2/pages/mypage/CounselStatus.tsx` 및 CSS.

- 사용자 레퍼런스의 요약 띠, 필터·표·페이지 이동, 오른쪽 일정·예약 안내를 반영했다. 유형 통계 대신 월간 캘린더를 사용한다.
- 공통 v2 셸의 여백·머리글·폰트와 기존 토큰을 유지한다. 모바일에서는 오른쪽 영역을 아래로 배치하고 표 내부만 가로 스크롤한다.
- 캘린더는 예정(대기·확정)과 완료를 구분한다. 날짜 클릭은 다른 필터를 초기화하고 해당 날짜를 조회한다. 같은 날짜를 다시 누르면 날짜 필터를 해제한다.
- 상담일이 미정이면 신청일을 상담일로 대체하지 않는다. 완료 기록의 날짜가 있으면 우선 사용한다. 최근 상담일은 완료 상담일의 최댓값이다.
- 기존 상담 유형(진로취업·심리·교수)과 대기 상담 취소 API를 유지했다. 상세보기는 학생 공개 코멘트만 표시한다.
- 검색, 상태·유형·기간 필터, 정렬, 페이지 크기를 제공한다. 사용자 추가 요청에 따라 CSV 다운로드는 제거했다.
- 기존 상담 스토어·공통 모달·아이콘·스토어 구독을 재사용한다. DB 스키마와 API 계약 변경은 없다.

검증: 프로덕션 빌드 및 대상 TSX ESLint 통과. Chrome MCP에서 테스트 DB의 학생 계정으로 화면 확인, 브라우저 메모리에만 추가한 가상 상담으로 같은 날짜 예정/완료 표시, 날짜 필터, 상태 탭, 10개/2개 페이지 이동, 다가오는 일정 3개, 상세 공개 코멘트 및 비공개 정보 미노출 확인. 데스크톱 1440px과 좁은 화면 500px에서 배치 확인. 요청 추가 없이 로컬 필터 동작, 기존 알림 폴링 200, 최종 콘솔 오류·경고 없음. 실제 상담 취소는 실행하지 않았다. 가상 상담은 DB에 저장하지 않았다.


## 학생·상담사 공용화

- `shared/components/CounselHistory.tsx` 및 CSS가 요약·검색·필터·표·페이지 이동·캘린더·상세보기의 단일 구현이다. CSV 코드와 버튼은 제거했다.
- 학생 `CounselStatus`는 본인 데이터와 학생 취소 함수를 전달한다. 상담사 `src_admin/pages/CounselHistory.tsx`는 기존 내 담당 상담 셀렉터, 학생 이름·학번, 기존 관리 화면 링크를 전달한다. 상담사 화면에 학생용 취소 기능을 연결하지 않는다.
- `/admin/counsel/records`를 상담기록 화면으로 등록했다. 기존 `/admin/counsel/journals`의 작성·관리 기능은 유지한다. 조회 범위는 기존 상담일지와 같은 내 담당 상담이며 전체 상태를 표시한다.
- `095_counsel_history_menu.sql`: 기존 메뉴 코드 0~7을 유지하고 `counsel.8`을 추가했다. 배열 중간 삽입은 DB 코드 매핑을 깨므로 코드상 마지막에 추가하고 표시 순서를 DB로 조절했다. 권한은 career/psych뿐이다. 테스트 DB와 로컬 dreamcatch에 적용했다.
- 복구는 새 마이그레이션에서 `counsel.8`을 비활성화하고 기존 메뉴 순서를 원래 코드 접미사 값으로 복원한다. 적용한 마이그레이션은 수정하지 않는다.
- Chrome MCP: 학생 CSV 제거 및 학생 열 미노출, 상담사 학생 열·날짜 필터·상세·관리 링크 확인. 기존 메뉴명과 경로 유지 확인. 두 화면 콘솔 오류·경고 없음. 상담 데이터 요청 HTTP 200. 메뉴 계약 테스트 1개, 빌드 및 대상 TSX ESLint 통과.


## 관리자 CSV 및 상담일지 상세보기 추가

- 관리자만 공용 뷰의 `onExport`를 전달해 현재 필터 결과 전체를 CSV로 내려받는다. 학생 페이지는 전달하지 않으므로 버튼이 없다. 기존 `counselExport.ts`의 CSV 직렬화를 재사용하며 수식 시작 문자와 인용부호를 안전하게 처리한다.
- 관리자만 `onOpenDetail`을 전달하여 기본 학생 상세 대신 상담일지 모달을 연다. `CounselRecordContext`로 기존 권한 검사 API에서 최신 일지를 읽는다. 없는 일지는 명시적인 미작성 안내를 표시한다.
- `CounselJournalBody`는 기존 상담일지 대장의 펼침 본문을 이동한 공용 컴포넌트이다. 대장과 상담기록 상세가 동일한 컴포넌트를 import한다. 비공개 내용은 관리자 컴포넌트에서만 렌더한다. 작성·수정은 기존 상담일지 페이지에서 계속 수행한다.
- Chrome MCP: 완료 필터 2건 CSV(헤더 포함 3줄), 상담일지 모달 및 본문, 학생 CSV 미노출 확인. 최종 빌드·대상 파일 ESLint 통과, 콘솔 오류·경고 없음. 이번 변경에 추가 DB/API 변경은 없다.
