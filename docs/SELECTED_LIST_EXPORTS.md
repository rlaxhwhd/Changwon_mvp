# 목록 선택 다운로드

2026-09-22 확정: 행 번호 앞 체크박스로 선택한 항목만 다운로드한다. 선택이 없으면 다운로드 버튼을 비활성화한다. 머리글은 현재 페이지 전체 선택이며, 페이지 이동 시 선택 유지, 검색·필터 변경 시 초기화한다.

## 적용

- 전체학생: 선택 ID를 POST `/academic-students/export`로 전달한다. 기존 검색 조건과 권한 검사를 유지하며 서버에서 선택 ID와 교집합을 XLSX로 생성한다.
- 상담기록, 상담 신청/일정, 상담일지: 선택한 상담 행만 CSV로 생성한다.
- 비교과 블랙리스트, 지도교수 배정: 선택한 목록 행만 CSV로 생성한다. 다운로드를 위해 전체 페이지를 추가 조회하지 않는다.
- 채용 지원자 상세: POST `/job-applications/export`에 applicationIds를 전달하며 기존 조회 권한과 다운로드 감사를 유지한다.
- 채용 공고별 지원자 목록: 선택한 공고의 지원자만 포함한다. 선택하지 않으면 전체 다운로드하던 동작을 제거했다.
- 비교과 프로그램 관리: 기존 선택한 프로그램의 신청자/참여자 명단 다운로드를 유지한다.
- 학생 목록이 없는 상담 통계 차트의 집계 CSV는 변경하지 않았다.

공통 선택 구현: `shared/useExportSelection.tsx`. 현재 페이지 일부 선택 상태를 표시하고, 체크박스 클릭·키보드 조작이 행 상세 열기로 전파되지 않게 한다. 로딩 중 이전 목록 선택을 막는다.

## 검증

- TypeScript 및 Docker api/web 빌드 성공.
- 학사학생·채용 API 테스트 38건 통과: 선택 ID, 중복 ID, 빈 선택, 필터 교집합, 권한, CSV 감사 검증 포함. 기존 게이트 테스트의 리셋 학생 기대값도 현행 확정 유형 없음 정책에 맞게 수정했다.
- Chrome: 전체학생 페이지를 넘겨 2명 선택 후 XLSX 200(113ms, 1,779bytes), 필터 변경 초기화, 머리글 전체/일부 선택 표시 확인.
- Chrome: 상담기록 2개 페이지에서 2건 선택, 실제 CSV 2건 확인. 상담일지·상담신청·지도교수 배정 각각 1건 선택 다운로드 확인. 상담 일정 화면에서도 체크박스 확인.
- 비교과 관리·채용 공고 목록 체크박스 확인. 비교과 블랙리스트·개별 채용 지원자는 로컬 데이터가 없어 빈 화면과 다운로드 비활성화만 브라우저에서 확인했다. 채용 선택 내보내기는 테스트 DB에서 검증했다.
- 최종 확인 화면 콘솔 오류 없음. 컨테이너 교체 중 일시적인 연결 종료는 재접속 후 재현되지 않았다.
- 전체학생 기존 목록 요청은 약 1.0~1.6초, 메타데이터는 2.26초였다. 공통 부팅 시 프로그램/채용 응답은 각각 약 0.7MB이며 여러 집계 호출도 존재한다. 이번 변경은 다운로드에서 전체 페이지 순회 요청을 없애며, 공통 부팅 최적화는 포함하지 않는다.

DB 스키마/마이그레이션 변경 없음.
