Page: /v2/diagnosis/employment

The action is remembered per student/test in sessionStorage for the current tab.

diagnosis reload and profile reload. Only a current completed HRTest attempt
with a matching result opens the report. Empty, incomplete or review results
show an alert and restore Start. Transport errors preserve View results for retry.

review action buttons. Existing test availability and server completion rules apply.
