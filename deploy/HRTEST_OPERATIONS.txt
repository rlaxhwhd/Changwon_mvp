HRTest integration release - 2026-10-01

Deployed images:
  dreamcatch-api:hrtest-20261001
  dreamcatch-web:hrtest-20261001
Only API/web were recreated. DB, SearXNG, RAG, Qdrant and LLM tunnel container IDs
were unchanged. GPU server was not modified or restarted by this release.

Flow (updated 2026-10-07): one action per assessment. Start opens the external
test in a new browser tab and changes the action to View results. View results
imports current provider results before opening the report. Missing/incomplete
results show an alert and reset the action to Start. Transport errors retain
View results for retry. See DIAGNOSIS_FLOW_OPERATIONS.txt for the release checks.
No iframe, question submission, auto-completion or synthesized diagnosis scores.
Student identity comes only from the authenticated student's stored student number.
Routes: Core=base, C2=jinro, C3=deft, C4=ready at
https://cwnu.hrtest.net/poll_before.asp?jst=...
Results API: Core=core, C2=cares, C3=deft, C4=ready.
C1/C5/C6 have no confirmed result/launch integration and remain unavailable.

Core mapping: 진로미탐색형=T1, 진로설정형=T2, 역량성장형=T3,
취업준비형=T4, 취약관리형=T5, 우수인재형=T6.
The provider's original label remains in the report; the site's T1 label remains
진로탐색형. Existing counseling type priority is preserved.
incomplete=true: INCOMPLETE, no accepted completion, no type/AI/gate credit.
Unclassified/unknown Core type: REVIEW, preserve scores and show confirmation
required; no accepted completion, type assignment or diagnosis AI analysis.
Do not infer why a result is unclassified.
