Knowledge source: deploy/rag/corpus.json, eight reviewed project-policy documents.
No personal student or counseling records are indexed. Context is read with
existing API permissions for each request. Student context excludes private
counseling summary, follow-up and form fields. Comment generation has no web
tools and does not save or finalize records. Roadmap generation retains its
existing draft/adoption/version/idempotency workflow and saves source versions.

This is retrieval-augmented generation, not fine-tuning. It is an initial
project-policy corpus, not a complete occupational or university handbook.
Reviewed source additions require updating corpus.json and rebuilding the RAG
image. Corpus SHA256 creates a new collection; old collections are not deleted.
Personal information, secrets, unreviewed web pages and sample score tables
must not be added to this shared corpus. Latest public facts use SearXNG.
