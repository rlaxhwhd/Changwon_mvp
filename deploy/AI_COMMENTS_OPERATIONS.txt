GET /api/v1/ai/comments uses the same card parameters and authorization as POST.

No DB connection is held during the LLM request. Before saving, the current user
and evidence permissions are revalidated on a fresh short transaction. Save failure
returns an SSE error, never success. Navigating away leaves an admitted comment
task running to completion and saving; the existing two-request limit still applies.
Tasks are in-process: stopping/restarting the API during generation can interrupt
unfinished work. This is not a persistent job queue.
