# 0008 · 이미지 분석 (원본 캡처 서술) — 조교 "전담교수 배정 현황"

> 사용자가 제공한 현행 운영시스템 캡처를 **Claude(팀장)가 육안 판독해 문자로 옮긴 것**이다.
> 이미지 파일 자체는 대화에만 존재하므로, 이후 단계(Codex·리뷰어)는 **이 문서를 이미지 대용 원본**으로 취급한다.
> ⚠️ 이 문서는 "현행이 이렇게 생겼다"의 기록일 뿐이다. **진실의 원천은 팀장이 교정한 `ui-spec.md`.**

## 2. 판독한 사실

| 요소 | 관찰 |
|---|---|
| 탭 | `전체` · `미배정` · `배정` 3개. 배정 여부로 목록을 가르는 축 |
| 필터 | ① 배정년도(기본 '배정년도전체') ② 학년(기본 '학년전체') ③ 넓은 셀렉트(기본 '전체' — 소속/학과 계열로 추정) ④ 자유 검색어 + [검색] |
| 버튼줄 | 초기화 / 전담교수 다운로드 / 엑셀업로드 / 엑셀다운로드 |
| 카운트 | "총 98개" — 필터 적용 결과 건수 |
| 표 열 | 체크박스 · 번호 · 학번 · 이름 · 소속 · 학년 · 연락처 · 지도교수 · 배정일자 (9열) |
| 번호 | **내림차순**(98→94). 최신 배정이 위 |
| 소속 | `단과대학 학부 전공` 이 한 셀에 들어가 2줄로 줄바꿈됨 |
| 지도교수 | **녹색 텍스트**(강조). 셀 정렬은 가운데 |
| 배정일자 | `YYYY.MM.DD` 점 구분 |
| 정렬 | 전 열 가운데 정렬, 행 구분선만 있는 플랫 테이블 |
| 팔레트 | 현행 사이트 녹색 계열(#0A7D3E 계열) + 주황 포인트 |

## 3. 사용자가 말로 추가한 요구 (이미지에는 안 보이는 상태)

> "배정되지 않은 학생들에겐 '지도교수' 열에 교수명이 아닌 **교수 배정 버튼**이 존재해"

즉 지도교수 열은 **두 가지 상태**를 가진다.
- 배정됨 → 교수 이름(강조 텍스트) + 배정일자
- 미배정 → `교수 배정` **버튼** (누르면 배정 플로우), 배정일자는 `—`

## 4. 프로젝트 부적합 요소 (팀장이 교정해야 할 후보)

| 이미지 요소 | 문제 | 교정 방향 (팀장 판단) |
|---|---|---|
| 녹색/주황 팔레트 | 드림캐치 백오피스 토큰(`--color-primary` 블루 계열)과 충돌 | **DESIGN.md 토큰만 사용.** 이미지 색 복제 금지 |
| 엑셀업로드 | 백엔드 없음 + 조교 권한 밖(대량 배정 변경) | 제외 판단 필요 |
| 전담교수 다운로드 / 엑셀다운로드 2종 | 기능 중복 | 하나로 통합 판단 필요 |
| "총 98개" | 조교는 **담당 학과만** 본다(FU_ASS_DEPT) — 98은 전교 규모 | 담당 학과 범위 카운트로 대체 |
| 소속 문자열 | 현행은 `GAST-인공지능대학 …` 창원대 실제 조직명. 우리 mock 학과 체계와 다름 | 우리 단일소스(학과→단과대 파생)로 표기 |
