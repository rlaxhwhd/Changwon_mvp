## Q1. 지원 왕복을 무엇으로 열 것인가 → **미결 #41 을 지금 정한다 (선택지 B)**

Opus 권고안(A: 텍스트 자소서로 우회)을 택하지 않았다. **파일 저장을 지금 확정하고
첨부를 처음부터 넣는다.** 나중에 바꾸면 이미 쌓인 첨부를 다시 옮겨야 한다는
`DB.md` #41 의 경고를 그대로 따른 것이다.

### #41-① 저장 위치 → **컨테이너 볼륨**

`pgdata` 옆에 파일 전용 명명 볼륨을 하나 더 만들어 서버 디스크에 둔다.

- 오브젝트 스토리지·MinIO 를 도입하지 않는다. 새 서비스 구축과 학교망 협의가
  선행돼야 해서 채용 착수가 그만큼 늦어진다.
- **DB 안에 바이너리로 넣지 않는다.** 백업이 무거워지고 복구가 길어진다 — #41 이
  경계한 방향이다.
- ⚠️ 볼륨은 **DB 백업에 포함되지 않는다.** 파일 볼륨 백업을 별도로 잡아야 하며,
  서버를 옮길 때 함께 옮겨야 한다. 이 운영 항목을 `DB.md` §9 에 새 미결로 남긴다.

### #41-② 접근 권한 판정 → **API 가 중개한다** (사용자 질문 아님 — 문서에 답이 있다)

`spec_v1.md` §5.4 가 공통 `file` 모델을 **「웹루트 밖 보관 + 다운로드 권한 검증」**으로
이미 규정했고(spec_v1:335), 이 시스템은 DB 조차 서버 로컬에만 열려 있다. 파일만
정적 서빙하면 그 방침이 깨진다.

- 파일은 **웹루트 밖** 볼륨에 저장하고 정적 서빙하지 않는다.
- 다운로드는 FastAPI 엔드포인트가 **요청자 권한을 확인한 뒤** 스트리밍한다.
  권한 판정은 새로 만들지 않고 기존 경로를 쓴다 — 학생은 본인 소유, 교직원은
  `dc.staff_student_scope`, 메뉴 접근은 `dc.menu_auth`(교정 E02).
- 저장 파일명은 서버가 부여한다. 업로드된 원본 이름을 경로에 쓰지 않는다.

### #41-③ 기존 `data:` URL 이미지 → **새 것부터 파일로, 기존은 둔다**

- 앞으로 올리는 이미지·첨부만 파일 저장소로 간다.
- 비교과 상세(§8-6 `detail`)에 이미 박혀 있는 `data:` URL 은 **건드리지 않는다.**
  변환 마이그레이션과 그 검증이 채용 착수를 늦추고, 기존 화면이 깨질 위험을 진다.
- 한동안 두 방식이 공존한다. 이 공존은 의도된 것이며 결함으로 보고하지 않는다.

### 이 결정이 되살리는 범위

D01 로 분리됐던 **공고 첨부 · 기업 로고 · 지원 서류 제출**이 이번 범위로 들어온다.
Opus 가 지적한 「J2 는 테스트만 되고 쓸 수 없는 엔진」 문제가 해소되어,
**공고 → 지원 → 상태이력 → 통계 왕복이 이번 도메인 안에서 닫힌다.**

D03(포트폴리오 provider)은 그대로 보류한다. 포트폴리오 도메인은 미착수이고(§8-3 4번),
`INITIAL_*` 상수를 provider 로 승격하지 않는다는 원 판단이 옳다.

## Q2. 지원 개인정보 동의 → **이번 범위에서 제외한다**

- 동의 테이블·검증·차단 로직을 이번에 만들지 않는다.
- **「동의 없으면 지원 차단」은 설계가 스스로 만든 차단이다**(Opus E13·D02). 그 차단을
  넣지 않으므로 지원은 동의 없이 성립한다.
- 도입할 때는 **jobs 사유물로 만들지 않는다.** 공통 `dc.consent_policy` /
  `dc.consent_receipt` 로 설계하고 jobs 는 `subject_kind` 로 참조만 한다 —
  비교과의 jsonb 동의도 나중에 같은 모델로 수렴시켜야 한다.
- **임시 문안을 지어내지 않는다.** 동의는 법적 효력이 있는 기록이라, 임시 문안으로
  받으면 그 동의가 무효가 되고 이력만 남는다.
- `DB.md` §9 에 후속 미결로 남긴다.

## Q3. 「채용시 마감」 → **최초 등록일 + 1개월 고정**

- Opus E11 의 버그 교정을 채택한다. 현행은 저장할 때마다 `등록일+1개월`을 다시
  계산해 **담당자가 오타 하나 고쳐도 마감이 한 달 밀린다.**
- 마감일은 **최초 등록 시 한 번만** 계산해 저장하고, 이후 수정에서 재계산하지 않는다.
- 무기한으로 바꾸지 않는다. 현행 동작의 의도(한 달)는 살린다.
